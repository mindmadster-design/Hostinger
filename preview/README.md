# SILIQ — Static Preview

A static HTML preview of the SILIQ luxury 925 sterling silver jewellery website.
This is **Phase 1**: a design preview you can open in any browser. After you
approve the look, it will be ported to a full WordPress + WooCommerce theme
(Phase 2) for deployment on Hostinger.

## Open it

Just open `preview/index.html` in any browser, or visit it via the GitHub Pages
URL once published.

## What's inside

```
preview/
├── index.html
├── assets/
│   ├── css/main.css
│   └── js/main.js
└── README.md
```

## Design tokens

| Token       | Value      | Use                  |
|-------------|------------|----------------------|
| `--bone`    | `#F4F1EC`  | Page background      |
| `--onyx`    | `#0F0F10`  | Primary text / dark  |
| `--graphite`| `#2A2A2C`  | Body text            |
| `--stone`   | `#888782`  | Muted text           |
| `--silver`  | `#B8B5AE`  | Accents              |
| `--ivory`   | `#EFEAE0`  | Cards / muted bg     |
| `--line`    | `#E5E1D8`  | Hairline borders     |

**Typography:** Cormorant Garamond (headings) + Italiana (display italics) +
Inter (body), all via Google Fonts.

## Images
